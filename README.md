# EndlessRunner3D
### 어떤 게임인가?
-> 캐릭터가 앞으로 자동으로 전진하고, 장애물을 피하며 아이템을 먹는 게임 (like 쿠키런)

### 배우는 핵심 기능
- 오브젝트 자동 생성: 장애물과 아이템이 계속해서 생성되게 만들기
- 오브젝트 삭제 및 메모리 관리: 화면 뒤로 지나간 장애물을 삭제하여 게임이 느려지지 않게 처리
- 속도 증가 시스템: 시간이 지날수록 점점 빨라지게 해, 난이도 만들기
- 게임 오버 & 재시작: 장애물 충돌시, 게임 오버 UI 띄우기, 재시작 버튼 만들기

2. 개념 복습
